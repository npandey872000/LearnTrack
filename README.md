# LearnTrack

LearnTrack is a collection of beginner-friendly Java projects for practicing core programming concepts.

## Projects

### Student Library Management System

A menu-driven console program for a school library. It lets you:

- Add books and register students.
- Issue books to registered students and record returns.
- View available and checked-out books.
- Sort the book list by title or author.

See the [Student Library Management System README](student-projects/library-management/README.md) for setup and run instructions.

## Requirements

- Java 8 or later

Projects are self-contained. Follow the README inside a project folder to compile and run it.
